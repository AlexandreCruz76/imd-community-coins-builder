## Prompt para Geração de Imagem

### English (para Midjourney/DALL-E)

```
Create a promotional banner for cryptocurrency token called "Builder Coin ($BUILDER)".

STYLE: Cyberpunk, neon, dark background with green and pink accents.

MAIN CHARACTER: A cute green robot called "Hookie" with:
- Green metallic body (#00FF88)
- Pink sunglasses (#FF0088)
- Holding a wrench in one hand
- Hook on top of head
- Friendly but confident expression

COMPOSITION: Hookie riding a pink unicorn (reference to Uniswap), moving forward through a neon city at night.

TEXT ELEMENTS (top to bottom):
- Header: "BUILDER COIN $BUILDER" with logo
- Main title: "ONCHAIN IS OUR TURF. WE BUILD. WE RIDE."
- Speech bubble: "HOOKIE IS BUILDING. ARE YOU?"
- Features list with icons:
  - SHIPS CODE - From idea to onchain
  - DELIVERS PRODUCT - Real value. Real usage
  - GROWS COMMUNITY - Builders attract builders
  - BURNS SUPPLY
- Slogan: "MORE HOOKS THAN A HOOKR"
- Badge: "BUILT DIFFERENT. ONCHAIN FOREVER."
- Footer: "BORN FROM @SURFCODEREPEAT ECOSYSTEM | BUILT BY DEGENS | FOR BUILDERS"

COLORS:
- Primary: Green #00FF88
- Secondary: Pink #FF0088
- Background: Dark black #0A0A0A
- Accent: ETH Blue #627EEA

MOOD: Energetic, futuristic, community-driven, fun but professional.

Uniswap logo subtly visible in the background.
```
